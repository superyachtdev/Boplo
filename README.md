# Boplo

The Boplo student-team workspace prototype.

## Deploy with Cloudflare Pages

Connect this GitHub repository in Cloudflare Pages, then use:

- **Production branch:** `main`
- **Framework preset:** None
- **Build command:** Leave blank
- **Build output directory:** `dist`

The site is static: no package installation or build step is required.

## Current prototype behaviour

- Project data is saved in the visitor's browser using local storage.
- Assignment briefs can be uploaded or pasted when creating a project.
- Real authentication, shared team workspaces, persistent file storage, document extraction, and billing require a backend before public launch.
