# Boplo

Boplo is a personal shoot planner. Choose a location, date, and visual mood to get a simple plan for when to go and what to shoot.

## Deploy with Cloudflare Pages

Connect this GitHub repository in Cloudflare Pages, then use:

- **Production branch:** `main`
- **Framework preset:** None
- **Build command:** Leave blank
- **Build output directory:** `dist`

The site is static: no package installation or build step is required.

## Current prototype behaviour

- The landing page includes an in-browser Scout Plan prototype.
- Visitors can enter a place, date, and visual mood to receive an illustrative shoot plan.
- Waitlist and plan interactions are local browser interactions; live light mapping, forecasts, account data, and email capture require a backend before public launch.
